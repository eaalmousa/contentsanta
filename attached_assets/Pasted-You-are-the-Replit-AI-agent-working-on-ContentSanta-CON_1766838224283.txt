2) SMART SOURCE DISCOVERY (RSS + NON-RSS)
────────────────────────────────

Users must NEVER be asked to paste RSS URLs.

Instead:
- Users define parameters:
  - query / topic
  - language
  - country / region
  - publication type (news, blog, research, etc.)

The system then automatically discovers sources using this order:
1) RSS / Atom feeds (preferred)
2) XML sitemaps
3) Known publisher patterns
4) Approved fallback extraction (only if explicitly allowed)

For each candidate source:
- Validate feed availability
- Validate XML correctness
- Apply existing RSS hardening rules
- Assign a trust tier

────────────────────────────────
3) MEDIA TIERS (SAFETY & QUALITY)
────────────────────────────────

Introduce Media Tiers that affect system behavior (not just labels):

Tier 1 — Authoritative
- Major, trusted publishers
- Eligible for auto-publish

Tier 2 — Credible
- Standard outlets
- Eligible for publish with review or stricter thresholds

Tier 3 — Unknown / Unverified
- Manual review only
- Never auto-published

Tiers affect:
- Deduplication strictness
- Publishing permissions
- Default review mode

────────────────────────────────
4) STORY-LEVEL DEDUPLICATION (CRITICAL)
────────────────────────────────

Current content-hash deduplication is correct and MUST remain.
Add a SECOND layer: story-level clustering.

Goal:
Prevent duplicate stories even when:
- Titles differ
- Writing styles differ
- URLs differ
- Sources differ

Implementation (incremental, safe):
- Introduce Story Clusters

Conceptual model:
- source_items → canonical ingested items (existing)
- stories → represent a single real-world event/topic
- story_items → link multiple source_items to one story

Clustering logic:
- Use normalized title + excerpt
- Extract key entities (ORG, PERSON, LOCATION)
- Use publish date bucket (e.g., same day)
- Apply semantic similarity (or SimHash/MinHash initially)

Rules:
- If similarity ≥ threshold → attach to existing story
- Else → create new story

Result:
- ONE story per event
- Multiple sources attached as provenance
