You are the Replit AI agent working on the ContentSanta repo.

OBJECTIVE
Implement the missing “Recommended Sources (toggle)” step in the Topic creation flow, based on our agreed product behavior:
- The user defines: (1) content intent/type, (2) topic/query, (3) geo scope (region + country), language
- THEN the system discovers and recommends sources
- The user reviews the recommended sources and toggles which ones are allowed for this topic
- No RSS setup is exposed to the user (feeds are internal)
- Topic runs only on the enabled sources

NON-NEGOTIABLE PRODUCT RULES
1) Users do NOT add RSS links. Users only curate trust by toggling suggested sources.
2) Geo scope is explicit and required: region + country (country can be multi-select if supported; if not, start with single country and design for multi-select later).
3) Source recommendations must be tier-aware and quality-aware:
   - tiers: TIER_1, TIER_2, TIER_3 (or numeric 1/2/3)
   - include a score/explanation (freshness + relevance + credibility) and show it in UI
4) Deduplication remains story-level later (not part of this step). This step only controls which sources can be used.
5) UX must be simple: “Suggested sources” list + toggles + “Select all Tier 1” convenience.
6) Everything must be persisted per Topic and respected by discovery/ingestion.
