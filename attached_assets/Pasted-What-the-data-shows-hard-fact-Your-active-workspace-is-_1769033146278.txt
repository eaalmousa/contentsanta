Doesn’t break multi-tenant.

Works for every new customer automatically.

Keeps demo-workspace as a system catalog.

Backend patch (copy sources from demo-workspace into active workspace)
1) Create a helper: ensureWorkspaceSeededSources(workspaceId)

Logic:

Count sources for workspaceId

If count == 0:

Insert copies of sources where workspaceId = "demo-workspace"

Set workspaceId to the user’s workspace

Keep everything else the same

Avoid duplicates using a uniqueness key (best: feedUrl + workspaceId)

Pseudo-code (Node/Drizzle-ish):

const SYSTEM_WORKSPACE_ID = "demo-workspace";

export async function ensureWorkspaceSeededSources(workspaceId: string) {
  const existing = await db.select({ n: sql<number>`count(*)` })
    .from(sources)
    .where(eq(sources.workspaceId, workspaceId));

  if ((existing[0]?.n ?? 0) > 0) return { seeded: false };

  const systemSources = await db.select().from(sources)
    .where(eq(sources.workspaceId, SYSTEM_WORKSPACE_ID));

  if (systemSources.length === 0) return { seeded: false, reason: "no_system_sources" };

  // Insert copies
  for (const s of systemSources) {
    await db.insert(sources).values({
      ...pickFieldsYouWant(s),
      id: crypto.randomUUID(),           // important: new id
      workspaceId,
      createdAt: new Date(),
      updatedAt: new Date(),
    }).onConflictDoNothing({
      target: [sources.workspaceId, sources.feedUrl], // add unique index if missing
    });
  }

  return { seeded: true, count: systemSources.length };
}


Important: don’t “UPDATE workspaceId” from demo → real. That would steal the shared catalog and break other users later. Always COPY.

Call ensureWorkspaceSeededSources(activeWorkspaceId) before any endpoint that needs sources:

GET /api/sources

POST /api/topics/recommend-sources

any “topic create sources step” endpoint

That guarantees the modal never loads empty for a new workspace.

Right now, you’re halfway between them, so it breaks.
